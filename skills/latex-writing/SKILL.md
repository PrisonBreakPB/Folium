# LaTeX Writing Skill

Use this workflow when editing or generating academic writing in TeX.

## Workflow

1. Read the relevant TeX or BibTeX files before editing.
2. Preserve the existing document style, macros, citation commands, and section structure.
3. Make focused edits. Do not rewrite unrelated sections.
4. Keep claims source-aware and leave citation placeholders only when the source is unknown.
5. For equations, prefer valid LaTeX syntax and define symbols near first use.
6. After editing, run a lightweight verification when possible, such as checking file contents or compiling if the project supports it.

## Writing Style

- Use concise academic prose.
- Avoid unsupported claims and marketing language.
- For related work, group papers by theme or method rather than listing them one by one.
