# Literature Review Skill

Use this workflow when the task involves surveying papers, comparing methods, or writing research background.

## Workflow

1. Clarify the research question, scope, and expected output format when they are unclear.
2. Gather evidence from papers, local files, or web sources before synthesizing.
3. Organize findings by problem, method, dataset, metric, result, limitation, and open question.
4. Prefer comparison tables for methods, datasets, metrics, and reported results.
5. Keep claims tied to sources. Mention title, author or venue, and year when available.
6. Separate evidence from interpretation. Mark uncertain claims as uncertain.

## Output Shape

- Short answer first when the user asks a direct comparison.
- For reports, use sections: background, taxonomy, key papers, comparison, gaps, references.
- For related work, write coherent paragraphs rather than a bullet dump.
